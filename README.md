# ElementLab

(Aufgrund des Umfangs wird dieses Projekt auf Englisch geschrieben und erklärt.)

A C application that focuses on compactly visualizing the abilities and characteristics of chemical elements.

## Main idea

Visually comparing element properties and creating a simulation for alloys.

## Path

1. Creating the visualization of the main menu (element and options buttons)
2. adding the characteristics through an open api
3. ...

## Project goal

Learning both course modules "Programmiersprache C" and "Werkstoffe und Halbleiter" for my bachelors degree.
